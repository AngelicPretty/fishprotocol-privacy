This Privacy Policy applies to Cyberpunk Theme for KLWP (package: fishprotocol.kustom.pack), developed by FishProtocol.

1. Data Collection

This application provides KLWP theme presets. The app does not require account registration and does not directly request personal information from users.

The developer does not operate user accounts or cloud-based personal data storage for this theme. Any locally stored app data can generally be removed by clearing app data or uninstalling the app.
